# DEMOCRACY 계정 삭제

## 앱에서 지우기

1. 앱의 지역구 화면 오른쪽 위 계정 버튼을 누릅니다.
2. 내 계정 → 계정 삭제를 누릅니다.
3. 쓴 글도 함께 지울지 고르고 확인합니다.

바로 지워지며, 되돌릴 수 없습니다.

## 앱을 쓸 수 없을 때

rush94434@gmail.com 으로 아래를 보내 주세요.

- 제목: 계정 삭제 요청
- 로그인에 쓴 방법 (Apple, Google, 카카오, 이메일)과 그 이메일 주소, 또는 활동명
- 쓴 글도 지울지 여부

| 항목 | 처리 |
|---|---|
| 로그인 정보, 이메일, 활동명, 동의 기록, 알림 설정 | 바로 삭제 |
| 주민 인증 결과 | 바로 삭제 |
| 쓴 글 | "글도 삭제"를 고르면 삭제. 아니면 남고 작성자가 "탈퇴한 주민"으로 바뀜 |
| 서버 접속 기록 | 최대 7일 뒤 자동 삭제 |
