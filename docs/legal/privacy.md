# DEMOCRACY 개인정보처리방침

시행일: 2026년 10월 2일

DEMOCRACY(이하 "앱")는 국회의원과 선거에 관한 공개 기록을 보여 주는 앱입니다. 기록을 읽는 데에는 계정이 필요 없고, 개인정보도 받지 않습니다. 평가나 채팅을 쓰려고 로그인하는 경우에만 아래 정보를 처리합니다.

## 1. 처리하는 개인정보와 목적

| 항목 | 언제 | 목적 |
|---|---|---|
| 로그인 제공자 식별자 (Apple, Google, 카카오, 이메일) | 로그인할 때 | 같은 사람인지 확인 |
| 이메일 주소 | 제공자가 넘겨줄 때, 이메일 로그인할 때 | 로그인 코드 발송, 계정 문의 응대 |
| 활동명 | 가입할 때 앱이 정해 줌 | 글 작성자 표시 |
| 동의 기록 (항목, 약관 버전, 시각) | 가입할 때 | 동의 사실 증빙 |
| 알림 수신 여부 | 가입할 때, 바꿀 때 | 알림 발송 여부 결정 |
| 주민 인증 결과 (선거구, 인증 시각, 만료일, 인증 토큰의 해시값) | 주민 인증할 때 | 해당 선거구 주민만 그 지역구에 글을 쓰게 함 |
| 작성한 평가·채팅과 작성 시각 | 글을 쓸 때 | 글 게시 |
| 접속 기록 (IP 주소, 요청 시각) | 서버에 요청할 때 | 장애 대응, 부정 이용 방지 |

앱은 실명, 휴대폰 번호, 주민등록번호, 생년월일을 받지 않습니다. 만 14세 이상인지는 가입할 때 본인 확인 항목으로만 묻습니다.

### 주소와 위치

지역구를 찾거나 주민 인증을 할 때 입력한 주소나 현재 위치 좌표는 서버로 보내 선거구를 찾는 데만 쓰고, 찾은 즉시 버립니다. 서버와 기록 어디에도 남기지 않습니다. 앱이 기억하는 건 찾은 선거구뿐이고, 그것도 이 기기 안에만 저장됩니다.

위치 권한은 "현재 위치로 찾기"를 누를 때만 요청하며, 대략적인 위치만 씁니다.

### AI 기능

공약·법안 대조와 방향 분석은 기기 안의 모델(Apple Foundation Models, Gemini Nano)이 처리합니다. 입력한 관심사와 분석 결과는 서버로 보내지 않습니다.

### 광고·추적

광고를 넣지 않고, 다른 회사의 앱이나 웹사이트에 걸친 추적을 하지 않으며, 분석 도구로 이용 기록을 수집하지 않습니다.

## 2. 보유 기간

- 계정 정보와 동의 기록: 계정을 삭제할 때까지. 삭제하면 지체 없이 파기합니다.
- 주민 인증 결과: 인증 후 180일. 지나면 효력이 없어지고, 다시 인증하거나 계정을 삭제할 때 지워집니다.
- 작성한 글: 계정을 삭제할 때 "내 글도 삭제"를 고르면 함께 지웁니다. 고르지 않으면 글은 남되 작성자는 "탈퇴한 주민"으로 바뀌고 계정과의 연결은 끊깁니다.
- 가입을 끝내지 않은 로그인 기록: 24시간 안에 자동으로 지웁니다.
- 만 14세 미만으로 응답한 경우: 그 자리에서 계정을 지웁니다.
- 접속 기록: 서버 제공자의 로그 보관 기간(최대 7일)이 지나면 지워집니다.

## 4. 이용자의 권리

언제든 아래를 요청할 수 있습니다.

- 열람: 앱 → 내 계정 → 내 데이터 내려받기
- 정정: 활동명은 내 계정에서 30일에 한 번 바꿀 수 있습니다
- 삭제: 앱 → 내 계정 → 계정 삭제. 앱을 쓸 수 없으면 [계정 삭제 안내](../account-deletion/)를 보세요
- 처리 정지와 동의 철회: 계정 삭제로 할 수 있고, 알림 동의는 내 계정에서 끌 수 있습니다

이메일로 요청하면 10일 안에 처리하고 결과를 알려 드립니다.

- 서버와의 통신은 모두 암호화(HTTPS)합니다.
