정치적 중립 UI 가이드라인 (필수 규칙)

N-1. 당색 금지. 정당은 색이 아닌 회색 아웃라인 태그 + 텍스트로만 표기. 빨강·파랑·초록 등 당 연상 색을 데이터 색으로 쓰지 않는다.
N-2. 동일 규격 카드. 모든 후보 카드는 크기·사진 규격·정보 순서 동일. 정렬 기본값은 ‘기호순’이 아닌 가나다순, 정렬 기준 항상 노출.
N-3. 흑백 인물 사진. 프로필 사진은 grayscale 처리 — 색으로 인한 호감 편향 제거, 시스템 미학과 일치.
N-4. 출처 우선. 모든 수치 옆에 출처 뱃지(예: 열린국회정보 API·선관위) + 원문 URL. 출처 없는 수치는 렌더하지 않는다.
N-5. 판단 언어 금지. UI 카피는 서술형(“출석률 92%”)만. “우수한”, “실망스러운” 등 평가 형용사는 시민 리뷰 영역에만 존재.
N-6. AI 결과 = 참고 자료. AI 매칭 화면에는 상시 고지 배너(“공인 평가 아님·오픈소스 알고리즘”)와 검증 링크를 고정 노출.

05  AI 맞춤 후보 분석 (킬러 기능)

신뢰가 생명인 화면. 고지 배너(N-6)를 결과 위에 고정하고, 1위 카드만 레이더+바 확장, 2·3위는 컴팩트 행으로 위계를 만든다. ‘왜 유리한가’는 ExpansionTile — 근거 문장마다 공보 원문 링크.
CustomScrollView
├ SliverAppBar (제목 + 프로필 요약, 탭 시 프로필 수정 sheet)
├ SliverPersistentHeader → 중립 고지 배너 (pinned)
├ SliverToBoxAdapter → 1위 MatchCard
│  ├ fl_chart RadarChart (5축, 축 = 사용자 관심 분야)
│  ├ 항목별 점수 Row[] (AnimatedFractionallySizedBox)
│  └ ExpansionTile “왜 유리한가” (LLM 근거 + 출처 링크)
├ SliverList → 2위 이하 컴팩트 카드 (탭 → 확장 상세)
└ SliverToBoxAdapter → 프리미엄 CTA
인터랙션: 레이더 축 탭 → 해당 항목 근거로 스크롤 · 점수 산출 중에는 skeleton + “분석 중 · 공약 42건 대조” 프로그레스 카피 · 순위 산출 로그(가중치·입력값)는 ‘알고리즘 검증’ 페이지에서 raw JSON으로 조회 가능. LLM 스트리밍 응답은 근거 텍스트 영역에 토큰 단위 렌더.

07  개표 및 선거 결과 시각화

지도 채색은 당색이 아닌 개표율 농도(회색 램프). 우세 후보는 지역구 탭 시 하단 패널의 바 차트로만 표시 — 지도 자체가 당 우세 지도가 되는 것을 구조적으로 차단(N-1).
Stack
├ GoogleMap (google_maps_flutter)
│  └ Polygon[] 지역구 경계 (선관위 GeoJSON) — fillColor: 개표율 농도
├ 상단 AppBar (선거명 + 개표율 + LIVE dot)
└ DraggableScrollableSheet (min .35)
   ├ 선택 지역구 득표 BarChart (fl_chart, 실시간 tween)
   ├ SegmentedButton (실시간·역대·여론조사)
   └ 역대: LineChart 연도별 · 여론조사: 공인 실선 vs 앱 점선
인터랙션: Polygon 탭 → 시트 확장 + 카메라 애니메이션 · 개표 데이터는 30초 폴링(선거일) / SSE, 득표 바는 TweenAnimationBuilder로 증가만 렌더 · 핀치 줌 레벨에 따라 시도 → 지역구 → 읍면동 단계 세분화 · 내 지역구는 항상 액센트 아웃라인 고정.

08  상태 관리 & 데이터 연동 (Riverpod 권장)

// 전역 인증·지역구 상태 — 모든 화면의 권한 게이트
enum AddressStatus { unverified, pending, verified }

final addressProvider = AsyncNotifierProvider<AddressNotifier, AddressState>(...);
final districtProvider = Provider((ref) => ref.watch(addressProvider).district);

// 화면별 데이터 — family + 캐싱
final legislatorProvider = FutureProvider.family((ref, districtId) => api.legislator(districtId));
final pledgeStatsProvider = FutureProvider.family(...); // 트래커
final aiMatchProvider = StreamProvider.family(...); // LLM 스트리밍

// 실시간 — 선거일 개표
final liveResultsProvider = StreamProvider.family((ref, districtId) => sse.watch('/results/$districtId'));
Riverpod 선택 이유 — 화면 대부분이 “지역구 ID → 파생 데이터” 구조라 family 프로바이더와 자동 캐시 무효화가 정확히 맞음. 주소 인증 변경 시 ref.invalidate(districtProvider) 한 줄로 전 화면 갱신.
인증 상태 전파 — 평가 작성·제보·채팅 버튼은 모두 ref.watch(addressProvider)를 구독해 verified가 아니면 disabled + 인증 유도 sheet. 게이트 로직은 위젯이 아닌 하나의 VerifiedGate 래퍼 위젯으로 통일.
실시간 계층 분리 — REST(프로필·공약) / SSE·WebSocket(개표·채팅) / LLM 스트림(AI 분석)을 별도 리포지토리로. 개표 폴링 주기는 서버 헤더로 제어(선거일 30s → 평시 daily).
오프라인·출처 — 모든 응답 모델에 sourceUrl, fetchedAt 필수 필드. 캐시 표시 시 “○월 ○일 기준” 스탬프 자동 렌더 — 출처 없는 데이터는 렌더 계층에서 assert로 차단.

09  iOS / Android 플랫폼 분리 설계

전략: 화면 구조·데이터·차트는 단일 코드(공통 위젯 트리 유지), 내비게이션·인증·알림·햅틱·시스템 통합만 플랫폼 분기. 분기는 위젯 안 if문이 아니라 PlatformAdaptive* 래퍼 위젯 계층 하나로 통일 — 유지보수 지점을 한 곳으로 모은다. 단, 중립 원칙상 Material You 동적 컬러는 비활성화(사용자 배경화면 색이 당색과 우연히 일치하는 리스크 차단): 양 플랫폼 모두 본 가이드의 무채색+시그널 레드 토큰 고정.

iOS 설계 (iOS 26+ · Liquid Glass)
디자인 언어 — Liquid Glass를 직접 그리지 않고 pub.dev 네이티브 패키지로 구현: ① native_liquid_glass — UiKitView 플랫폼 뷰로 애플 순정 Liquid Glass(UIKit 컨트롤)를 임베드, iOS 26+ 자동 적용·구버전은 시스템 기본 스타일 폴백 ② 탭바·버튼·슬라이더·스위치 등 컨트롤은 cupertino_native_better(하이브리드 컴포지션, 픽셀 퍼펙트) ③ 커스텀 카드·데이터 패널처럼 네이티브 컨트롤이 없는 서피스만 liquid_glass_widgets(셰이더 기반 GlassScaffold/GlassTabBar, Reduce Transparency 자동 대응)로 보완. 데이터 색·중립 규칙은 M3와 동일 토큰 공유.
내비게이션 — CupertinoPageRoute 스와이프-백 · 대시보드 헤더는 SliverAppBar 대신 CupertinoSliverNavigationBar(라지 타이틀 → 축소) · 하단 탭 CupertinoTabBar 규격(49pt).
주소 인증 — Face ID/Touch ID 재인증(local_auth) + iCloud Keychain 패스키(passkeys 패키지, WebAuthn) — 비밀번호 없는 로그인.
Live Activities — 선거일 개표율·내 지역구 1위를 잠금화면/Dynamic Island에 실시간 표시(live_activities 패키지 + ActivityKit). 킬러 네이티브 포인트.
홈 위젯 — WidgetKit(SwiftUI) + home_widget: 내 의원 공약이행률 도넛 스몰 위젯, 개표 미디엄 위젯.
App Intents / Siri — “내 의원 출석률 알려줘” 단축어 · Spotlight에 의원 프로필 인덱싱(Core Spotlight).
디테일 — 햅틱 UIImpactFeedback(도넛 섹션 탭·판정 확정) · 지도는 google_maps_flutter 대신 apple_maps_flutter 옵션 검토(네이티브 질감·배터리) · ScrollBehavior bouncing 유지.
🤖 Android 설계 (API 34+, Material 3)
내비게이션 — Predictive Back Gesture 대응(PopScope) · NavigationBar(M3, 80dp) + 상단 2px 보더 커스텀 · 대화면/폴더블은 NavigationRail 전환(지도+시트 2-pane).
주소 인증 — Credential Manager API 패스키 + 지문(BiometricPrompt, local_auth) · 통신사 본인인증 연동 시 SMS Retriever API로 OTP 자동 입력(smart_auth).
실시간 개표 — Live Updates/진행형 알림(Ongoing Activity) + 잠금화면 개표 진행 바 · FCM data 메시지로 30초 갱신.
홈 위젯 — Glance(Jetpack) + home_widget: 공약이행률·개표 위젯 iOS와 동일 정보 구조.
App Shortcuts / Assistant — 롱프레스 단축(내 지역구·AI 분석) · Google Assistant App Actions “개표 현황 보여줘”.
디테일 — Edge-to-edge + SystemUiMode.edgeToEdge · 햅틱 HapticFeedback.mediumImpact · Material You 동적 컬러 의도적 미적용(중립성) · 지도 renderer LATEST(클라우드 스타일링으로 무채색 지도 스타일 고정).
